OhMyDebn requires the following:

- x86_64 or ARM architecture
- 2GB RAM MINIMUM (more is obviously better)
- 2 CPU cores MINIMUM (more is obviously better)
- Debian 13, or a supported derivative like Linux Mint 22, Linux Mint Debian Edition 7, Kali Linux (Rolling), or Ubuntu 24.04/26.04 (no favorite? we recommend [Linux Mint Cinnamon Edition](installation.md#choosing-a-base-distro))
- non-root user account with sudo privileges
- curl
- ability to connect to Github, package repos, and other Internet sites
